# Beam Designer (Tkinter)

Beam Designer is a Python desktop app for analyzing simply supported and
cantilever beams. It supports point and uniform loads, displays shear, moment,
and deflection diagrams, checks steel and lumber sections, and exports saved
designs, CSV results, and PDF calculation sheets.

## Install

Use Python 3.10 or newer. Install the package used for PDF export:

```powershell
pip install matplotlib
```

Tkinter is included with most Python installations on Windows.

## Start
```powershell
python main.py
```
